## 它能做什么

26 个工具，覆盖工作簿、工作表、单元格读写、格式、条件格式、数据验证、表格、图表、汇总表，以及只读的 VBA 查看。
它和 `mcp-office` 互补：**office 生成新文件，excel 读取并修改已有文件**。

## 实测结果

- 带 token 才能访问；绑 `0.0.0.0` 且没有 token 时，服务会**拒绝启动**。
- 有 `create_chart`（图表）。**没有名叫"透视表"的工具**，最接近的是 `create_summary_table`。

## 文件从哪来

它操作的是**服务器上**的文件（限定在 `--allow-dir` 目录内，我们的部署里是 `excel-data` 卷）。目前文件只能由管理员放进去，
**还没有远程用户上传文件的通道**。

## 安全

自带 Bearer token 和目录白名单；上游文档说明网络类函数的公式会被拒绝，单次最多处理 10 万个单元格。
我们在网关后再套一层统一鉴权，并用内部 token 替换用户的 token 访问它。
